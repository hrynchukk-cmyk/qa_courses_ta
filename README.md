# Tech Assurance QA Academy — лендінг

Лендінг-сторінка курсу **«Manual QA Engineer»** від Tech Assurance QA Academy.

Один самодостатній файл — `index.html` (стилі та скрипти вбудовані), без збірки
та залежностей. Підходить для хостингу на GitHub Pages, Netlify, Vercel або
будь-якому статичному хостингу.

## Запуск локально

Просто відкрийте `index.html` у браузері, або:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## Публікація на GitHub Pages

Settings → Pages → Source: обрати гілку та корінь репозиторію (`/`).

## Кастомізація

### Фірмові кольори

Усі кольори винесені в CSS-змінні на початку `<style>` в `index.html`
(блок `:root` — світла тема, `@media (prefers-color-scheme: dark)` +
`:root[data-theme="dark"]` — темна). Щоб привести сторінку у відповідність
до брендбуку Tech Assurance, замініть значення:

| Змінна | Призначення |
|---|---|
| `--accent` | основний брендовий колір (кнопки, посилання, акценти) |
| `--paper` / `--card` | фон сторінки / фон карток |
| `--ink` / `--muted` | основний та другорядний текст |
| `--pass` / `--fail` / `--warn` | семантичні кольори QA (пройдено/дефект/попередження) |

### Email для заявок

Форма заявки працює через `mailto:` (відкриває поштовий клієнт відвідувача).
Адреса задається констою `APPLY_EMAIL` у `<script>` внизу `index.html`;
ця сама адреса показана в блоці контактів. За потреби підключіть
замість цього реальний бекенд або сервіс на кшталт Formspree — замініть
обробник `submit` на звичайний `action` форми.

### Шрифти

Підключені через Google Fonts (усі — з повною підтримкою кирилиці):

- **Unbounded** — заголовки
- **Golos Text** — основний текст
- **JetBrains Mono** — технічні акценти («термінал», лейбли, коди модулів)
