# Tech Assurance — лендінг QA-напряму

Статичний сайт Tech Assurance для QA-аудиторії. Дві сторінки:

- **`index.html`** — курс **«Manual QA Engineer»** (Tech Assurance QA Academy);
- **`reverse-recruiting.html`** — послуга **Reverse Recruiting** для QA-кандидатів.

Без збірки та залежностей. Спільний дизайн винесено в `assets/` — обидві
сторінки використовують один набір стилів і скриптів, тож оформлення не
«розповзається». Підходить для GitHub Pages, Netlify, Vercel або будь-якого
статичного хостингу.

## Структура файлів

```
index.html               ← курс Manual QA Engineer
reverse-recruiting.html  ← послуга Reverse Recruiting
assets/
  styles.css             ← спільна дизайн-система (токени, шапка, картки…)
  main.js                ← спільна логіка (меню, форма → mailto, анімації)
  favicon.svg            ← фавікон (синя плитка + QA-«галочка»)
  favicon-32.png         ← PNG-фолбек 32×32
  apple-touch-icon.png   ← іконка для iOS (180×180)
README.md
```

Сторінки перелінковані: у шапці курсу є пункт **Reverse Recruiting**, а в
шапці Reverse Recruiting — **Курс Manual QA**.

## Запуск локально

Оскільки сторінки підключають файли з `assets/`, відкривайте через локальний
сервер (а не просто `file://`):

```bash
python3 -m http.server 8000
# → http://localhost:8000            (курс)
# → http://localhost:8000/reverse-recruiting.html
```

## Публікація

- **GitHub Pages:** Settings → Pages → Source: гілка та корінь репозиторію (`/`).
- **Vercel / Netlify:** імпортувати репозиторій; білд не потрібен
  (Framework Preset — *Other*, Build Command і Output порожні).

## Кастомізація

### Фірмові кольори

Усі кольори — CSS-змінні на початку **`assets/styles.css`** (блок `:root` —
світла тема; `@media (prefers-color-scheme: dark)` + `:root[data-theme="dark"]`
— темна). Один файл змінює обидві сторінки.

| Змінна | Призначення |
|---|---|
| `--accent` | основний брендовий колір (кнопки, посилання, акценти) |
| `--paper` / `--card` | фон сторінки / фон карток |
| `--ink` / `--muted` | основний та другорядний текст |
| `--pass` / `--fail` / `--warn` | семантичні кольори QA (пройдено/дефект/попередження) |

### Email для заявок

Обидві форми працюють через `mailto:` (відкривають поштовий клієнт відвідувача).
Адреса та тема листа задаються атрибутами на самому тегу `<form>`:

```html
<form ... data-mailto="hrynchukk@techassurance.agency"
          data-subject="Заявка на курс Manual QA Engineer">
```

Спільний обробник у `assets/main.js` збирає лист із полів `name`, `contact`,
`message`. Щоб змінити адресу чи тему — правте `data-mailto` / `data-subject`
у відповідній сторінці. Для реального бекенда (напр. Formspree) замініть
обробник `submit` на звичайний `action` форми.

### Шрифти

Google Fonts (усі — з повною підтримкою кирилиці): **Unbounded** (заголовки),
**Golos Text** (основний текст), **JetBrains Mono** (технічні акценти).

## Структура сторінок

### `index.html` — курс Manual QA Engineer

Побудовано навколо мети найму найкращих випускників у команду Tech Assurance:

1. Hero з анімованим «прогоном тестів» (фінал — офер у Tech Assurance)
2. Працевлаштування: повний курс із працевлаштуванням, шлях «Навчання → Офер»
3. Зарплатна сітка QA: Trainee $450 і Junior $650 (стартові ставки),
   Middle $1800 і Senior $3200 (медіани [DOU, зима 2026](https://dou.ua/lenta/articles/salary-report-qa-winter-2026/))
4. Про курс — навички випускника
5. Формат навчання
6. Програма (24 теми, 6 модулів)
7. Окремий модуль «AI у QA»
8. Практичний проєкт (захист = технічна співбесіда)
9. Чим програма відрізняється
10. Форма заявки

### `reverse-recruiting.html` — Reverse Recruiting для QA

Послуга: як практикуюча QA-компанія допомагаємо кандидатам знайти роботу
та ведемо весь рекрутинговий процес на боці кандидата.

1. Hero з панеллю «метчінгу кандидата»
2. Що таке reverse recruiting (працюємо на вас, ведемо весь процес, ми самі QA)
3. Процес: 5 кроків — інтерв'ю → огляд навичок → резюме → метчінг → підготовка
   до технічної співбесіди
4. Для кого (щойно з курсів / досвідчені, але недооцінені / не вміють себе продати)
5. Що враховуємо (зарплата, формат, домен, стек, команда, розвиток, англійська, графік)
6. Чому саме Tech Assurance
7. Форма заявки
