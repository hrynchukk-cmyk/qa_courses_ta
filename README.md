# Tech Assurance — рекрутинговий лендінг

Статичний сайт рекрутингових послуг Tech Assurance. Дві сторінки:

- **`index.html`** — головна: **Recruitment** — підбір персоналу для бізнесу (B2B);
- **`reverse-recruiting.html`** — **Reverse Recruiting** для кандидатів (допомога у пошуку роботи).

Без збірки та залежностей. Спільний дизайн — в `assets/`, тож обидві сторінки
використовують один набір стилів і скриптів. Хостинг — Vercel (домен
`techassurance.academy`).

## Структура файлів

```
index.html               ← головна: Recruitment для бізнесу
reverse-recruiting.html  ← Reverse Recruiting для кандидатів
vercel.json              ← редірект зі старого /recruitment.html на /
assets/
  styles.css             ← спільна дизайн-система (токени, шапка, картки…)
  main.js                ← спільна логіка (меню, форма → mailto, анімації, аналітика)
  favicon.svg            ← фавікон
  favicon-32.png         ← PNG-фолбек 32×32
  apple-touch-icon.png   ← іконка для iOS (180×180)
README.md
```

Сторінки перелінковані: у шапці головної є пункт **Для кандидатів**
(→ Reverse Recruiting), а на сторінці кандидатів — **Для бізнесу** (→ головна).

## Запуск локально

Сторінки підключають файли з `assets/`, тож відкривайте через локальний сервер:

```bash
python3 -m http.server 8000
# → http://localhost:8000              (головна, Recruitment)
# → http://localhost:8000/reverse-recruiting.html
```

## Кастомізація

### Фірмові кольори

Усі кольори — CSS-змінні на початку **`assets/styles.css`** (блок `:root` —
світла тема; `@media (prefers-color-scheme: dark)` + `:root[data-theme="dark"]`
— темна). Один файл змінює обидві сторінки.

| Змінна | Призначення |
|---|---|
| `--accent` | основний брендовий колір (кнопки, посилання, акценти) |
| `--paper` / `--card` | фон сторінки / фон карток |
| `--ink` / `--muted` | основний та другорядний текст |
| `--pass` / `--fail` / `--warn` | семантичні кольори (успіх / помилка / попередження) |

### Пошта форм

Обидві форми працюють через `mailto:`. Адреса й тема листа задаються
атрибутами на тегу `<form>`:

```html
<form ... data-mailto="hrynchukk@techassurance.agency"
          data-subject="Запит на підбір персоналу (B2B)">
```

Спільний обробник у `assets/main.js` збирає лист із підписів полів форми.
Для реального бекенда (напр. Formspree) замініть обробник `submit` на
звичайний `action` форми.

### Шрифти

Google Fonts (усі — з підтримкою кирилиці): **Unbounded** (заголовки),
**Golos Text** (основний текст), **JetBrains Mono** (технічні акценти).

## Структура сторінок

### `index.html` — Recruitment (B2B)

1. Hero з пайплайном найму + CTA «Залишити вакансію» / «Запланувати дзвінок»
2. Кого наймаємо (ролі)
3. Як це працює (бриф → пошук → шортліст → офер → гарантія)
4. Чому Tech Assurance
5. Модель співпраці (оплата за результат + гарантія заміни)
6. Форма «Залишити вакансію»

### `reverse-recruiting.html` — для кандидатів

Hero, кейси (зарплата до/після), процес, для кого, що враховуємо,
відгуки, тарифи (Resume / Job Search / Full Representation), форма заявки.
